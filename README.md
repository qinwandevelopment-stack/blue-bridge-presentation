# الجسر الازرق

مشروع عرض مستقل لمبادرة الجسر الازرق الرقمي.

## التشغيل

يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي من داخل هذا المجلد:

```powershell
python -m http.server 8000
```

ثم فتح الرابط:

```text
http://localhost:8000/index.html
```

## المحتويات

- `index.html`: العرض المستقل.
- `media/`: الصور الاصلية المستخرجة من العرض.
- `render-*.html`: قوالب تجريبية للصور المولدة، محفوظة للرجوع فقط.
